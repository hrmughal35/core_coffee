# Hero video

Add a high-resolution coffee video here for the homepage hero background.

**Filename:** `hero.mp4`

- **Format:** MP4 (H.264)
- **Length:** 10–30 seconds (will loop)
- **Resolution:** 1920×1080 or higher
- **Size:** Keep under ~15 MB for fast loading (or use a compressed clip)

If `hero.mp4` is missing or fails to load, the site automatically shows the static hero image instead.

## Free stock video sources

- **Pexels:** https://www.pexels.com/search/videos/coffee/  
- **Coverr:** https://coverr.co/videos/coffee  
- **Pixabay:** https://pixabay.com/videos/search/coffee/

Download a clip you like, rename it to `hero.mp4`, and place it in this folder.
